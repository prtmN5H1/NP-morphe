## ◈ Overview

**NP Morphe** is a modified community fork of [Morphe](https://github.com/MorpheApp/morphe-manager), created by **prtmN5H1** with AI-assisted tweaks. It inherits the foundation of [ReVanced Manager](https://github.com/ReVanced/revanced-manager) and [URV](https://github.com/Jman-Github/Universal-ReVanced-Manager), while layering on small customizations for a tailored patching experience.

> **Privacy first.** Everything happens locally. NP Morphe never uploads your APKs or personal data anywhere.

## ▸ Getting Started

### 1. Install

Download and install the latest build:

&nbsp;&nbsp;&nbsp;&nbsp;**[NP Morphe — Releases](https://github.com/prtmN5H1/NP-morphe/releases)**

### 2. Pick an app

YouTube, YouTube Music, and Reddit are supported out of the box.

### 3. Choose your mode

| Mode | Description |
| :--- | :--- |
| **Simple** | One-tap experience. Tap **Patch** and NP Morphe applies sensible defaults — no configuration needed. |
| **Expert** | Full control. Select exactly which of the 100+ patches to apply, configure per-patch options (colors, toggles, and more), and fine-tune everything before patching. |

### 4. Provide the APK

NP Morphe guides you through obtaining the original app file via step-by-step dialogs. **Patching happens entirely on your device.**

### 5. Install and enjoy

Once patching completes, install the result like any normal APK.

## ◈ Features

### Patch Sources
- Add any compatible patch bundle via **GitHub URL** or **deep link**
- **Per-source pre-release toggle** for early patch access
- **Automatic background update notifications** (even when the app is closed)
- Sort your app list and patch sources however you like — by name, install date, and more

### Installer
- **Standard Android installer**
- **Shizuku / Shizuku+ / Sui** — installs with no confirmation dialog
- **Root installer** with Magisk module support (mount-based, no data loss on update)
- **Play Store installer variants** — so Google Play recognizes itself as the install source *(with a warning: Play Store may then offer updates that overwrite your patched build)*
- **Third-party installers** detected on your system are also available as an option
- **Prompt-on-install** — choose per session
- On **rooted devices**, NP Morphe asks whether you want a **Root Mount** or **Standard** install before patching begins, and adjusts the applied patches to match your choice

## ▸ New to GitHub?

If you landed here and aren't sure what to do next — no worries. Here's the short version:

1. Go to the **[Releases page](https://github.com/prtmN5H1/NP-morphe/releases)**.
2. Under **Assets**, tap the file ending in `.apk` to download it.
3. Open the downloaded file on your Android device and tap **Install**.
4. If Android asks you to allow installs from unknown sources, follow the prompt to enable it — this is required for any app not from the Play Store.

That's it. Once NP Morphe is installed, everything else happens inside the app — the **[guides](docs/README.md)** walk you through your first patch.

For FAQs and troubleshooting, visit **[morphe.software](https://morphe.software)** or join the community on **[Reddit](https://www.reddit.com/r/MorpheApp)**.
